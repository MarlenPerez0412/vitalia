# VITALIA

Plataforma HealthTech/AgeTech para promover autonomia, bienestar y seguridad en personas adultas mayores y su red de apoyo.

## Desarrollo

Requisitos: Node.js 24+ y npm 11+.

```bash
npm install
npm start
```

La aplicacion queda disponible en `http://localhost:4200`. Los accesos de esta etapa son perfiles simulados seleccionables desde `/login`.

## Validacion

```bash
npm run build
npm test -- --watch=false
```

Antes de contribuir, leer `AGENTS.md` y la memoria tecnica de `docs/`.
